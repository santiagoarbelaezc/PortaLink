<h1 align="center">🔗 PortaLink - Dashboard Portfolio CMS</h1>

<h3 align="center">🚀 Plataforma para la gestión dinámica de contenido de portafolios personales y profesionales</h3>

<p align="center">
  Aplicación web full‑stack para la administración de secciones, servicios, proyectos y analíticas de un portafolio web.<br>
  Frontend en Angular, Backend en Node.js (REST API) con Express, y base de datos MySQL.
</p>

## 📋 **Descripción del Proyecto**

**PortaLink** es un sistema de gestión de contenidos (CMS) diseñado específicamente para portafolios web. Permite a los profesionales administrar de manera centralizada su información personal, servicios, habilidades, proyectos destacados y visualizar métricas de visitas a través de una interfaz de administrador intuitiva y moderna.

> ⚠️ **Estado del Proyecto:** En desarrollo activo

---

## 🏗️ **Dashboard**

**PortaLink Dashboard Admin**: Panel administrativo protegido para gestionar el contenido visible en el portafolio público. Incluye la creación, edición y eliminación de servicios, proyectos, configuración de secciones estáticas y visualización de analíticas de visitas.

## 🏪 **Características del Sistema**

### **🔍 Gestión de Portafolio**
- Configuración global dinámica (secciones hero, about, contacto).
- Gestión CRUD de Servicios y Habilidades (Skills).
- Gestión CRUD de Proyectos Destacados (con tech stack, imágenes y enlaces).

### **📊 Analíticas y Seguridad**
- Registro de visitas (páginas visitadas, referencias, IP).
- Autenticación robusta de usuarios administradores mediante JSON Web Tokens (JWT).

---

## 📦 **Backend**

- API REST construida en Node.js y Express.
- Autenticación y protección de rutas mediante JWT y encriptación de contraseñas con bcryptjs.
- Conexión a base de datos relacional MySQL (mysql2).
- Entorno de desarrollo ágil con nodemon.

---

## 🖥️ **Frontend**

- Single‑page application (SPA) con Angular 21.
- Interfaz moderna y completamente responsive diseñada con Tailwind CSS.
- Panel de control (Dashboard) para la administración del contenido del portafolio.

---

## 🚀 **Cómo ejecutar el proyecto**

### Backend (Node.js)
```bash
cd portalink-backend
npm install
# configurar variables de entorno en .env
npm run dev
```

### Frontend (Angular)
```bash
cd portalink-frontend
npm install
npm start
```
